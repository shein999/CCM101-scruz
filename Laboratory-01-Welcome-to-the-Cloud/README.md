# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a Linux cloud
environment using KillerCoda and helped me begin building
my Cloud Computing portfolio using GitHub.

## Objectives

- Access a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

I accessed the KillerCoda Linux Playground using Ubuntu.
I created a Linux user account named scruz, configured a
password, and logged into the new account.

I also gathered information about the Linux distribution,
kernel, CPU, memory, and available disk space. I created
directories and Markdown files and prepared my GitHub
Cloud Computing portfolio.

## Skills Learned

I learned how to access a cloud-based Linux environment,
create and manage a Linux user, navigate the Linux file
system, gather system information, create Markdown files,
and organize my work using GitHub.
