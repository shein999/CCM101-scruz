# Reflection

This laboratory activity gave me my first practical experience
working with a cloud-based Linux environment through KillerCoda.

I learned how to create a Linux user, log into the account,
navigate the Linux file system, and use basic commands to
collect system information.

I also learned how to organize files using directories and
document technical work using Markdown.

Creating my GitHub Cloud Computing portfolio helped me
understand how technical work can be organized and maintained
in a version-controlled environment.

One of the things I found challenging was becoming familiar
with the Linux terminal and remembering the commands. However,
by following each step and checking the output of each command,
I became more comfortable using the terminal.

This activity helped me understand the importance of proper
documentation, organization, and version control in cloud
computing.
